This directory is intended for a public Doclira PDF information and support repository.

- Official website: `https://www.doclira.com/`
- English user guide: `https://www.doclira.com/guide/`
- Chinese user guide: `https://www.doclira.com/zh/guide/`

- Support email: `lienowen@outlook.com`

- Gumroad automatic license-key activation wording

## Do Not Publish Here

- Paid `.exe` or buyer ZIP packages
- License key batches or activation delivery records
- Private PDFs used in testing
- Application source that exposes license validation logic
- Gumroad-connected application source or build configuration

## Suggested GitHub Upload Scope

- `README.md`
- `README.zh-CN.md`
- `CHANGELOG.md`
- `SECURITY.md`
- `.github/ISSUE_TEMPLATE/`
