Doclira PDF Lite v0.1.0
========================

Free PDF basics for Windows 10 / 11 (64-bit).

Included in Lite:
- Open and preview PDF files locally
- Merge and split PDF files
- Rotate or remove a page and save a new copy
- Add a basic single-file text watermark

For batch processing, advanced watermark tools, conversion and lightweight
text correction, visit Doclira PDF Pro:
https://www.doclira.com/

Source code and issue tracker:
https://github.com/lienowen/doclira-pdf-lite
