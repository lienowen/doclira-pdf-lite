# Changelog

All notable public product changes will be recorded here.

## [1.0.0] - Launch Candidate

### Added

- Continuous PDF preview with lightweight text replacement, deletion and addition workflow.
- Visible batch file list with single or multi-file selection and progress display.
- Text and logo watermark operations with tiled placement, opacity, rotation and page range settings.
- PDF to Word and PDF to PNG page export.
- PDF compression presets, PDF merge and split, and images to PDF.
- Localized interface support for Chinese, English, Japanese, Korean, Spanish, French and German.
- Gumroad license-key activation for international delivery, with one-time online verification followed by offline local use.
- Dedicated English Windows installer workflow for Gumroad customers.

### Known Limits

- Text editing is intended for short corrections rather than complete complex PDF re-layout.
- Scanned files, encrypted files, uncommon embedded fonts and highly structured layouts can require manual follow-up.
- The initial Windows release targets 64-bit Windows 10 and Windows 11 only.
